Aim:
To understand the fundamental concepts of Python programming and its application in Exploratory Data Analysis (EDA).

Theory:
Python is a high-level, interpreted programming language known for its simple and readable syntax. It supports multiple data types such as integers, floats, strings, and lists, along with various operators that facilitate data manipulation and analysis. In this experiment, variables were created to store values, and the print() function was utilized to display outputs on the screen. Due to its versatility, extensive libraries, and ease of use, Python is widely employed for data handling, preprocessing, and exploratory data analysis tasks.

Conclusion:
This experiment provided a clear understanding of the basic concepts of Python programming, including variable assignment and output display using the print() function. It demonstrated how Python serves as an effective and efficient tool for performing preliminary data analysis and handling data operations.
